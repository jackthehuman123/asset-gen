# Requests

Asset requests from the agents building this game. The creator approves case by case; the pipeline agent fulfils them from the repo root with `/make <game> <asset>`.

Status: `pending` | `approved` | `built` | `rejected` (built, but not good enough by the creator's judgement).

## <asset> — pending
- Need: what it is, in words
- Where used: where it goes in the game
- Style notes: anything beyond this game's STYLE.md
- Result: (pipeline fills this in: output path, or the creator's rejection reason)
