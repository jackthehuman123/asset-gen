# Spike: Generation Detail Test (throwaway)

Run 6 question: **at its best (one piece, max triangle budget, a detail-heavy prompt), how detailed and
accurate can Roblox's generator get?**

## Run it
Paste `GenerationTest.server.lua` into a Script in ServerScriptService. Press **Play** (about 30–60 seconds).
You get one modern cabinet, 3 studs tall, in two copies next to a 5.5-stud marker:
1. **GENERATED**: Roblox's texture
2. **MATERIAL**: Roblox wood material

## Bring back
- The Output block.
- **Accuracy:** did you get two doors, three drawers, handles, thin legs, or something else?
- **Detail and edges:** panel seams, sharp corners, or melted and blobby?
- **Up close:** which copy holds up better?
